# 第三方许可与素材来源

本目录保留可在本机核实的上游许可原文。文件名仅标明原文出处，不表示同一许可覆盖整个项目。

- MaaPracticeBoilerplate 的 MIT 版权和许可见 `MaaPracticeBoilerplate-MIT.txt`；MaaCommonAssets 的 MIT 版权和许可见 `MaaCommonAssets-MIT.txt`。OCR 模型对应文件亦保留其来源 README；PaddleOCR 项目及相关模型卡声明 Apache 2.0，其正文见 `Apache-2.0.txt`。本地 ONNX 具体转换链尚未独立验证。
- `MaaFramework-LGPL-3.0.md` 是原项目保存的 MaaFramework LGPL 条款；具体依赖的实际版本和分发方式需分别核对。
- `PySide6-Fluent-Widgets-1.11.3-GPL.txt` 是原环境安装元数据附带的 GPLv3 条款；该组件另有商业许可选项，适用条款取决于实际取得方式。
- `ok-script-original-record.txt` 是原项目附带的 Apache 2.0、Commons Clause 和附加条款记录。实际 vendor 的 417 项与原项目来源记录匹配，但尚未对应到确定的上游提交或发行包，不能直接将这份记录认定为所有历史 vendor 文件的许可证。OK-WW v3.7.4 以及 ok-script 2.0.0b7 对应的历史上游版本使用 AGPL-3.0；`AGPL-3.0.txt` 为从本机 MaaAgentBinary 依赖原样取得的 AGPLv3 正文，不证明该正文必然适用于此 vendor 的每个文件。相关模板衍生文件和内嵌 Pyperclip、rotypes、Web bundle 的具体来源及适用条款仍须核对。
