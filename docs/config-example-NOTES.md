# 配置示例使用边界

`config.example.json` 是人工填写的字段示意，并非能够直接运行的配置。`null` 和尖括号文本都是占位符，不能用它们启动任务；请根据本机实际安装、设备实例及原项目策略填写完整值，另存为项目根目录的 `config.json`。原本机配置没有被复制进示例。

`platform` 为 MuMu 路径示例，`cli` 是所用命令行程序路径，`install_root` 是模拟器安装目录，`sdk` 是 SDK DLL 路径；均需按本机环境填写。`instance` 是模拟器实例编号。`cpu_pick` 是两个整数形式的界面坐标，使用前需要根据所需目标和界面分辨率验证；`cpu_label` 和 `target_order` 同样需要按实际需求与策略填写。示例并未验证任何输入值，不能保证 MuMu、PC 或具体游戏任务可用。

`config.json` 是本机运行设置，不应将填写后的配置、账号、通知设置或用户状态提交到公开仓库。现有工作副本缺少若干组件，不构成已验证的完整安装说明。
